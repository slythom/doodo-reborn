# doodo-reborn

Jeu de Perudo (Dudo / Liar's Dice) en ligne — beta Android, client Godot +
serveur Go autoritaire. Monorepo :

- `client/` — projet Godot (jeu)
- `server/` — serveur Go (WS, moteur de jeu, house rules, bots)
- `shared/` — contrat de messages client/serveur (`protocol.md`)
- `specs_*.md` — specs fonctionnelles, techniques, artistiques
- `ROADMAP.md` — milestones

Périmètre et décisions d'archi : `specs_techniques.md`.
